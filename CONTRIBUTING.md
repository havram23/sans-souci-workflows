# Mitwirken

Änderungen mit synthetischen Beispielen und Tests für das tatsächliche Fehlerrisiko einreichen. Python-Standardbibliothek bevorzugen; neue Dienste und Abhängigkeiten begründen. Bestehende Dateien nicht still überschreiben. Fehlende Daten nicht als erfolgreichen Zustand darstellen.

Vor einer Änderung alle Prüfungen aus README ausführen. Für n8n Quellcode in `n8n-src/` bearbeiten und mit `python tools/build_n8n.py` exportieren. Inhalte der Bibliothek stehen in `catalog.json`; Anleitungen und Website werden daraus gebaut.

Keine echten Kundennamen, E-Mail-Adressen, personenbezogenen Exporte, Schlüssel oder produktiven Endpunkte in Beispiele übernehmen. Für Beispieldomains `example.invalid` verwenden.
